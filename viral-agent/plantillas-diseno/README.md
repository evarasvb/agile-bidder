# Plantillas de diseño — posts del libro

Fuente editable de las 6 plantillas visuales (una por pilar de contenido) usadas
para los posts de Instagram/Facebook. Formato 1080x1350 (vertical IG).

Canvas publicado (editable en línea, exporta PNG/PDF):
https://claude.ai/code/artifact/f329d40c-6e88-4d53-b43b-41f3087af19e

- `Main.dc.html` — Mitos y errores comunes
- `Tips.dc.html` — Tips prácticos / checklist
- `Historias.dc.html` — Historias y casos reales
- `Backstage.dc.html` — Detrás de cámara
- `PruebaSocial.dc.html` — Prueba social / reseñas
- `CTA.dc.html` — CTA directo (venta del libro)

Todas usan el mismo sistema: fondo azul marino `#0A1626`, tipografía Anton
(titulares) + DM Sans (cuerpo), acentos rojo `#FF3B30` y dorado `#F5B301`, y un
placeholder marcado "FOTO AQUÍ" donde falta la foto real del autor — reemplázalo
antes de exportar/publicar.

Para editar: abre el link de arriba, usa el editor visual (clic para seleccionar,
edición de texto en línea), y guarda. Para exportar a imagen real y usarla en
`contenido/calendario_lanzamiento.csv` (columna `imagen_url`), usa "Export PNG"
desde el canvas y súbela a un hosting público (no hay hosting de imágenes en
este repo).
