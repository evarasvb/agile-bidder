# 🤖 Cómo Conversar con Evaristo

## 📍 Dónde Encontrar a Evaristo

### Opción 1: Página de Administración (Recomendado)

1. **Inicia sesión** en www.firmavb.cl
2. **Ve a**: `/admin/evaristo`
   - O desde el menú lateral, busca "Evaristo" o "Administración"
3. **Verás dos pestañas**:
   - **"Conversar con Evaristo"** - Chat interactivo
   - **"Panel de Control"** - Ejecución manual de comandos

### Opción 2: Desde el Menú

Si hay un enlace en el menú lateral:
- Busca "Evaristo" o "Admin" en el menú
- Haz clic para acceder

## 💬 Cómo Conversar

### Comandos Disponibles

1. **"revisar"** o **"revisa el código"**
   - Evaristo revisará todo el proyecto
   - Te mostrará problemas y mejoras

2. **"mision"** o **"ejecuta mision_completa_firmavb"**
   - Ejecuta la misión completa de optimización
   - Procesa todas las tareas automáticamente

3. **"ayuda"** o **"help"**
   - Muestra lista de comandos disponibles

4. **Preguntas directas**:
   - "¿Qué mejoras has hecho?"
   - "¿Cuál es el estado del proyecto?"
   - "Revisa el frontend"

### Ejemplo de Conversación

```
Tú: hola
Evaristo: ¡Hola! Soy Evaristo, tu programador autónomo...

Tú: revisar
Evaristo: ✅ Revisión completada exitosamente...

Tú: mision
Evaristo: ✅ Misión "mision_completa_firmavb.json" completada...
```

## 🎯 Funcionalidades

### Chat Interactivo
- Conversación natural
- Comandos por voz/texto
- Respuestas en tiempo real
- Historial de conversación

### Panel de Control
- Ejecución manual de comandos
- Ver estado de API keys
- Configurar API keys temporales
- Ver output detallado

## ⚠️ Notas Importantes

1. **Requiere autenticación**: Solo usuarios autenticados pueden acceder
2. **Edge Function debe estar desplegada**: Para que funcione remotamente
3. **API Keys configuradas**: En Supabase Secrets o temporalmente en el panel

## 🔧 Si No Funciona

1. **Verifica que estés autenticado**
2. **Revisa que la Edge Function esté desplegada**
3. **Confirma que las API Keys estén configuradas**
4. **Revisa la consola del navegador** para errores
